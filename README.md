# Linkin Park Ticket-Website (Gruppenprojekt)

Gruppenprojekt im Modul Webentwicklung, Hochschule Trier (Nov. 2024 – Jan. 2025), Team aus 4 Personen. Das vollständige Projekt liegt in einem privaten Repository. Dieses Repository enthält nur einen Teil der Dateien, an denen ich mitgearbeitet habe. Daten- und Bilddateien sind nicht enthalten, deshalb ist der Code hier nicht lauffähig.

## Mein Anteil
- Seite zum Ticketkauf (`content/tickets/buy_tickets.php`): Kaufen-Button für jede Veranstaltung über die Event-ID
- Sitemap-Seite mit eigenem Stylesheet (`sitemap.php`, `sitemap.css`)
- Überarbeitung des Mitglieder-Bereichs, u. a. Hover- und Fokus-Effekte, die auch per Tabulatortaste funktionieren
- Fehlerbehebungen an der Ticketsuche (`search.js`) und an der Über-uns-Seite (`about.html`)

Einige Dateien (z. B. `index.php`, `style.css`) wurden von mehreren Teammitgliedern bearbeitet.

## Technologien
PHP, HTML, CSS, JavaScript, Git/GitHub, PhpStorm

## Was ich gelernt habe
Ich habe gelernt, im Team mit Git und GitHub zu arbeiten und Änderungen von Teammitgliedern zusammenzuführen. Außerdem habe ich gesehen, wie wichtig Bedienbarkeit per Tastatur ist, und deshalb Hover- und Fokus-Effekte so angepasst, dass sie auch mit der Tabulatortaste funktionieren. Beim Ticketkauf habe ich in PHP mit Parametern aus der URL gearbeitet und Eingaben dabei bereinigt.
